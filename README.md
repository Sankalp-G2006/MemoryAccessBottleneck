# MemoryAccessBottleneck

Investigation and benchmarking of memory access bottlenecks and cache performance.

## Experiments

- [`initial experiment/`](./initial%20experiment/): Benchmark measuring memory read access times across varying strides, testing cache line and memory bandwidth effects.
- [`Clustering/`](./Clustering/): Radix clustering experiments and plotting scripts.
- [`QueryAlgorithms/`](./QueryAlgorithms/): Cache-conscious query algorithm experiments (`Exp-1`, `Exp-2`, `Exp-3.1`, `Exp-3.2`) including selection, grouping, and join benchmarks.
